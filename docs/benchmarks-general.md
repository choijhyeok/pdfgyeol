# 비보험 PDF에서의 읽기 순서와 표

보건 안내문, 세무 양식, 학술 논문의 본문에서 PDF결은 기준 문구 60쌍의 순서를 모두 맞혔습니다. 같은 구간에서 PyMuPDF 기본 모드와 pdfplumber의 텍스트 흐름 옵션도 60쌍을 맞혔습니다. 반면 한국어 재난 안내서의 그림 속 본문은 세 파서 모두 추출하지 못했고, 열차 시간표에서는 다른 두 파서만 역·열차 번호에 대응하는 시간을 복원했습니다.

## 비교한 문서

쪽수는 PDF 파일의 첫 페이지를 1로 센 번호입니다. 원본 링크에서 파일을 받아 아래 이름으로 저장하면 같은 비교를 실행할 수 있습니다. 두 비교 도구 모두 실행 전에 SHA-256으로 파일을 확인합니다.

| 보건 안내 | [CDC 독감 백신 안내문](https://www.cdc.gov/vaccines/hcp/current-vis/downloads/flu.pdf) | `cdc.pdf` | 2 | 1·2쪽의 2단 안내문 |

## 읽기 순서

각 페이지 이미지에서 읽는 순서대로 짧은 문구 5개를 지정한 뒤 파서를 실행했습니다. 한 페이지에 가능한 문구 쌍은 10개입니다. 두 문구가 각각 한 곳에서 식별되고 올바른 순서로 등장하면 1점입니다. 찾지 못한 문구가 들어간 쌍도 전체 분모에 포함했습니다. 대소문자·공백·제어 문자와 유니코드 호환 표기를 정규화했습니다. 그림 자체의 이해, 양식의 입력 필드 연결, 수식의 의미는 이 점수의 대상 밖입니다. [페이지별 기준 문구와 원본 해시](../tools/reading_order_cases.json)

| 지진 안내서 5쪽 | 0 | 0 | 0 | 0 | 0 |

| **전체 80쌍** | **60** | **51** | **60** | **60** | **51** |

지진 안내서 두 쪽에는 각각 이미지 1개와 원문 글자 조각 48개·29개가 있었습니다. 제목·쪽수 등 일부 글자는 추출됐지만, 화면에서 고른 본문 문구는 10개 모두 기본 텍스트 출력에 없었습니다. 세 파서는 이 비교에서 OCR을 사용하지 않았습니다.

## 표와 Decision

열차 시간표에서 PDF결은 지정한 역·열차·시간 12건 중 0건을 연결했고, pdfplumber와 PyMuPDF는 각각 12건을 연결했습니다. 논문 실험표에서는 세 파서 모두 지정한 행과 측정 지표의 교차 셀을 복원한 사례가 10건 중 0건이었습니다. 숫자가 텍스트에 남아도 올바른 행·열로 연결해야 표 점수를 얻습니다. [표별 정답과 실패 사례](benchmarks-tables.md)

위 표의 PDF결 수치는 Decision과 보험 옵션을 끈 기본 모드 결과입니다. 별도로 빈 W-9 양식 1쪽과 공개 시간표 1쪽에서는 Decision-1.1을 기본 임곗값으로 실행했습니다. W-9의 후보 영역 1곳과 시간표의 후보 영역 2곳 모두 점수가 모호해 보류했고, 두 페이지의 레이아웃은 기본 결과와 같았습니다.

## 재현

Python 3.12.11, PDF결 0.1.0, pdfplumber 0.11.11, pdfminer.six 20260107, PyMuPDF 2.2로 실행했습니다. 저장소를 설치한 환경에서 위 원본들을 같은 디렉터리에 둔 뒤 실행합니다. 출력 JSON에는 입력 해시, 버전, 항목별 점수가 들어 있습니다.

```sh
python -m pip install . "pdfplumber==0.11.11" "pdfminer.six==20260107" "PyMuPDF==2.2"
python tools/benchmark_order.py ./sources > reading-order.json
python tools/benchmark_tables.py ./sources > table-cells.json
```

원문 보존은 추가로 5개 문서 49쪽 전체에서 확인했습니다. 추출된 원문 글자 조각 82,515개가 페이지별 읽기 순서에 각각 한 번씩 등장했습니다. 이 검사는 조각의 누락·중복을 확인합니다. 레이아웃 정답을 대조한 범위는 위 표의 읽기 순서 8쪽과 표 2쪽이며, 각 분야에서 한 문서씩만 골랐습니다.
