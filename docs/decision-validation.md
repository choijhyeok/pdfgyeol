## 기존 후보 변경 통합 검토

직전 `ab4f6ed`의 `aligned_label_value_rows`는 4~16개의 짧고 띄어진 정렬 항목에서 기본 `columns`와 대안 `rows`를 만든다. 기존 `sparse_aligned_blocks`와 같은 페이지·셀 범위의 연속 ID 순열 계약을 사용하므로 판정기에 그대로 연결했다. 기하 구현은 수정하지 않았다. 4·8행 측정 PDF와 기존 기능 2 회귀 검사는 후보 계약·기본 읽기 순서 보존을 확인한다. 중첩 셀과 독립된 여러 후보의 적용은 별도로 검사한다.

## 자동 검사

```text
.venv/bin/python -m pytest -q tests/test_decision.py
.venv/bin/python -m pytest -q
.venv/bin/python -m mypy --strict src/pdfgyeol
git diff --check
```

최종 전체 검사 93개 통과, strict mypy 6개 소스 파일 통과, diff 공백 검사 통과. 테스트·라이브 검증 외 추가 의존성은 없다.

가짜 제공자는 대안을 실제 적용해 문자 ID를 기대 순서로 재배열하는지 확인한다. 부모·형제 셀, 루트의 전후 영역, 원문 객체, 줄·영역·표 좌표가 유지되는지 검사한다. 출처 ID의 `Counter`가 입력과 같고 각 ID가 한 번만 나오는지 검사한다. 실패·동점·낮거나 근접한 점수·비정상 수치·누락/추가 키·중복 JSON 키·원문 변경 시도·타임아웃·429·503·중복/순환 소유권·다른 셀 침범은 적용되지 않는다. 기본 모드와 무후보 모드는 환경/클라이언트 생성도 하지 않는다. 응답 실패 뒤 다른 국소 대안은 계속 처리한다.

## 실제 Decision-1.1 호출

소유자가 허용한 외부 `.env`의 endpoint·키·배포명을 메모리에서만 읽었다. endpoint·키·응답·발췌는 출력·복사·커밋하지 않았다. 다음 명령의 경로는 운영자가 허용한 파일로 바꿔 실행했다.

```text
.venv/bin/python tools/decision_live_probe.py --env-file /authorized/path/.env --run-live --report /tmp/pdfgyeol-feature3-live-results.json
```

완료된 실행의 집계:

| 항목 | 결과 |
|---|---:|
| 직접 생성한 비민감 PDF | 5 |
| 서로 다른 후보가 있는 국소 영역 | 4 |
| 실제 요청 / 정상 점수 응답 | 4 / 4 |
| 최대 상태 크기 | 9,431 UTF-8 bytes |
| 규칙 단독 / 판정 후 전체 순서 정답 | 2/5 → 2/5 |
| 개선 / 악화 | 0 / 0 |
| 보류: `ambiguous_scores` | 4 |
| 원문 보존 / 범위 밖 불변 | 모두 통과 |
| 비활성 / 무후보 요청 | 0 / 0 |

정답은 네트워크 호출 전 고정했다. 4행·8행 측정 목록과 중첩 셀은 행별 읽기가 정답이며 기본 단별 순서는 틀린 표본이다. 짧은 독립 본문 단과 무후보 대조군은 기본 순서가 정답이다. 기본 `min_score=0.55`, `min_margin=0.10`에서 네 응답 모두 보류되어 실제 대안 적용·품질 개선은 입증되지 않았다. 긍정적인 적용·순서 검증은 가짜 제공자 테스트의 결과다. 이 작은 개발 표본으로 실제 문서 정확도나 임곗값 보정을 주장하지 않는다.

앞선 검증 도구 실행은 네 영역의 요청 후 마지막 대조 PDF가 뜻하지 않게 후보를 생성해 중단됐다. 대조군의 줄 간격을 수정하고, 모든 표본의 후보·정답을 가짜 제공자로 먼저 검사한 뒤 최종 실행을 완료했다. 중단된 실행의 응답은 집계하지 않았다. 전체 라이브 요청 시도는 두 실행 합계 8회이며 위 표는 완료된 4회만 나타낸다. 모델 점수에 맞춰 후보·정답·기본 임곗값을 바꾸지 않았다.

## 리뷰에 남기는 제한

기능 3의 안전한 호출·보류·국소 적용 계약은 검사했다. 실제 Decision-1.1이 이 표본의 오독을 고친다는 증거는 없다. 더 많은 독립 표본과 점수 보정은 별도 평가가 필요하다. 실제 보험 문서나 사용자 문서는 이번 라이브 호출로 보내지 않았다. 기능 4·병합·게시 작업은 하지 않았다.
