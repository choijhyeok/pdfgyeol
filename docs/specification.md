# PDF결 첫 버전 개발 명세

PDF결은 PDF에서 단·표·문단의 경계와 읽기 순서를 복원한다. 기본 모드는 로컬에서 동작한다. 사용자가 Decision을 켜면 기하 규칙으로 구분하기 어려운 영역의 후보를 비교한다.

| 기능 | 산출물 | 합격 기준 |
|---|---|---|
| 1. 원문 추출 | pdfplumber 기반 페이지·텍스트 조각, 안정적인 ID, 페이지 좌표와 글꼴 정보 | 같은 파일을 두 번 읽어 같은 ID와 순서를 얻는다. 빈 페이지와 이미지 전용 페이지를 구분한다. |
| 2. 영역과 읽기 순서 | 단·전폭 제목·단 내부 표·병렬 표를 구분하는 규칙, 표의 행·셀과 원문 참조, 대안 순서 | 2단에서 왼쪽 본문을 먼저 읽고 표가 끝난 자리에서 본문을 재개한다. 각 원문 조각은 결과에서 한 번만 소비한다. |
| 3. Decision 판정 | 영역별 후보, 명시적으로 켜는 모델 호출, 선택·보류 기록 | 서로 다른 후보가 있는 영역에만 필요한 발췌와 배치를 보낸다. 실패·동점·유효하지 않은 응답은 기본 후보로 복귀한다. 모델 응답은 원문을 바꿀 수 없다. |
| 4. Python API·CLI | PDF를 구조화된 JSON으로 내보내는 설치 가능한 패키지 | 새 환경에 wheel을 설치해 API와 CLI로 같은 문서를 읽는다. 기본 모드는 키와 네트워크 없이 동작한다. |
| 5. 보험 옵션 | 조·특약·별표와 기존 블록의 소속 관계를 추가하는 선택 기능 | 옵션을 꺼도 코어의 블록·순서가 동일하고, 일반 문서에 보험 규칙이 적용되지 않는다. |
| 6. 저장소 안내 | 수달 마스코트, MIT 라이선스, 실제로 실행되는 설치·CLI·Python 예시, 한계와 예제 출력 | 새 사용자가 README만 보고 첫 PDF를 처리한다. 공개하지 않은 배포본이나 미검증 성능을 안내하지 않는다. |

## 검증

- 재배포 가능한 작은 PDF로 단일 단, 이중 단, 전폭 제목, 단 안의 표, 이미지 전용 페이지, 모호한 경계를 재현한다.
- 실제 자료는 보험 약관과 다른 문서 유형에서 확인한다. 원문 누락·중복, 읽기 순서 역전, 표의 셀 대응, Decision 호출 수를 규칙 단독 결과와 비교한다.
- 모델 관여가 결과를 개선하거나 악화시킨 사례와 근거를 기록한다. 개발에 사용한 표본과 독립 평가 표본을 구분한다.
